# YouTube Shorts Pipeline

**Подготовьте заготовку вертикального ролика из YouTube-ссылки или локального видео.** Проект на Python собирает в один процесс нарезку, транскрипцию, генерацию текстовых материалов и озвучку.

## Что умеет

- Получать исходное видео через `yt-dlp` (README проекта также заявляет поддержку proxy и cookies).
- Определять сцены и подготавливать вертикальные клипы 9:16 с FFmpeg.
- Транскрибировать аудио через Whisper.
- Генерировать хуки, описания и теги через DeepSeek API или локальный генератор.
- Создавать русскую озвучку с Microsoft Edge TTS.
- Обрабатывать локальные видеофайлы.

> Это инструмент подготовки материалов, а не автоматической публикации на YouTube. Проверяйте результат и права на исходное видео перед публикацией.

## Быстрый запуск

Нужны Python 3.11+, FFmpeg и зависимости проекта.

```bash
python youtube_shorts_pipeline.py "https://youtube.com/watch?v=..."
```

Локальный файл:

```bash
python youtube_shorts_pipeline.py "C:/video.mp4"
```

В Windows можно использовать `ЗАПУСК.bat`.

### Настройка

В текущем репозитории нет `requirements.txt` или отдельной инструкции установки зависимостей. Перед запуском установите библиотеки, используемые скриптом, проверьте наличие FFmpeg и настройте DeepSeek API key для облачной генерации. Конкретный список импортов и параметры конфигурации смотрите в `youtube_shorts_pipeline.py`.
